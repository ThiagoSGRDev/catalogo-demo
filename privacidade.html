Política de Privacidade

Última atualização: 14 de outubro de 2026

Resumo: coletamos só o necessário para o catálogo, o painel, os pedidos e as cobranças funcionarem.

Não vendemos dados e não usamos cookies de publicidade.

Os dados do cartão são digitados no Mercado Pago, e o Katalogo Hub não tem acesso a eles.

Para ver, corrigir ou apagar seus dados, escreva para katalogohub@gmail.com.

1. Quem é responsável pelos seus dados

O Katalogo Hub é operado por [NOME COMPLETO OU RAZÃO SOCIAL], CNPJ [CNPJ]. A responsabilidade muda conforme quem você é:

  • Lojista (quem assina o Katalogo Hub) e visitante do nosso site: o Katalogo Hub é o controlador dos seus dados, ou seja, decide como eles são usados.
  • Cliente de uma loja (quem compra no catálogo): a loja é a controladora dos seus dados de pedido. O Katalogo Hub é o operador: guarda e processa esses dados em nome da loja, só para o pedido funcionar.

Esta política segue a Lei Geral de Proteção de Dados (LGPD, Lei 13.709/2018).

3. O que fica guardado no seu aparelho

O catálogo guarda no navegador, sem mandar para nós:

  • os favoritos e o carrinho;
  • informações temporárias da visita: se o aviso de demonstração já apareceu, o pagamento em andamento e o link de campanha de onde você veio.

São dados técnicos, necessários para o site funcionar. Você pode apagá-los limpando os dados do site no navegador. Não usamos cookies de publicidade nem de rastreamento de terceiros.

4. Com quem compartilhamos

Não vendemos nem alugamos dados pessoais. Compartilhamos apenas com os fornecedores necessários para o serviço funcionar:

  • Supabase: banco de dados, login e armazenamento de fotos. Os servidores ficam em São Paulo (Brasil).
  • Vercel e Cloudflare: hospedagem do site e entrega das páginas.
  • Mercado Pago: processamento dos pagamentos online das lojas.
  • Asaas: cobrança da assinatura dos lojistas.
  • Serviço de envio de e-mails: e-mails da conta, como confirmação e troca de senha.
  • WhatsApp (Meta): quando o cliente envia o pedido para a loja pelo WhatsApp, a mensagem segue as regras do próprio WhatsApp.
  • A loja: recebe os dados do pedido do cliente para atendê-lo e fazer a entrega.
  • Autoridades: quando houver ordem judicial ou obrigação legal.

Alguns desses fornecedores podem tratar dados fora do Brasil. Nesses casos, usamos empresas que oferecem proteção compatível com a LGPD.

5. Por quanto tempo guardamos

  • Conta do lojista: enquanto a conta estiver ativa e por até 90 dias depois do cancelamento. Depois disso, os dados são apagados.
  • Registros de cobrança e de pedidos pagos: por 5 anos, para cumprir obrigações fiscais e do Código de Defesa do Consumidor.
  • Código de controle do teste grátis (gerado a partir do CPF): enquanto for necessário para evitar o uso repetido do teste.

6. Seus direitos

Pela LGPD, você pode pedir:

  • confirmação de que tratamos seus dados e acesso a eles;
  • correção de dados incompletos ou errados;
  • apagamento, bloqueio ou anonimização de dados desnecessários;
  • portabilidade dos dados para outro serviço;
  • informação sobre com quem compartilhamos;
  • revisão do uso de dados baseado em legítimo interesse, ou oposição a ele.

Para pedir, escreva para katalogohub@gmail.com. Respondemos em até 15 dias. Se você for cliente de uma loja, também pode pedir direto à loja. Encaminharemos à loja os pedidos sobre dados de pedidos dela.

Você também pode reclamar à Autoridade Nacional de Proteção de Dados (ANPD).

7. Segurança

  • Conexão criptografada (HTTPS) em todas as páginas.
  • Senhas guardadas de forma criptografada.
  • Regras no banco de dados que impedem uma loja de ver os dados de outra.
  • Chaves do Mercado Pago acessíveis só pelo servidor.

Nenhum sistema é 100% seguro. Se houver um incidente que traga risco a você, avisaremos você e a ANPD, como manda a lei.

8. Menores de idade

O painel do lojista é só para maiores de 18 anos. O catálogo das lojas não é feito para coletar dados de crianças.

9. Mudanças nesta política

Podemos atualizar esta política. A data no topo indica a versão atual. Mudanças importantes serão avisadas pelo painel ou por e-mail.
